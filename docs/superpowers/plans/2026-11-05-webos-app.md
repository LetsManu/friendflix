# LG TV app (webOS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** FriendFlix as an installable LG webOS app that opens the TV mode, sends a capability block so the server direct-plays what the TV confirms, handles LG remote keys, and ships as unsigned developer-mode `.ipk` files with install scripts.

**Architecture:** A packaged webOS web app (`webos/app`, local `file://` setup page) navigates to `https://<server>/tv?ff_app=webos`; everything LG-specific on the server page lives in `web/src/lib/webos/` behind `isLgApp()`. The backend only learns `client: 'webos'`. Packaging uses the pinned `@webos-tools/cli` (ares); CI builds and attaches the `.ipk` files to the GitHub Release without secrets.

**Tech Stack:** SvelteKit/TypeScript (web), Node test runner (`webos/`, `tv-shared/`), vitest, Playwright, zod (backend), `@webos-tools/cli` 3.2.6, bash + PowerShell.

**Spec:** `docs/superpowers/specs/2026-11-05-webos-app-design.md`

## Global Constraints

- App id `com.friendflix.tv`, probe id `com.friendflix.tv.probe`; titles "FriendFlix" / "FriendFlix Test".
- Version comes from `version.json` (strict `X.Y.Z`), stamped at build time; tracked `appinfo.json` files are never edited by the build.
- Server address: HTTPS only (`FFSetupCore.normaliseServer`); stored in `localStorage` `ff.server` / `ff.authOrigin`.
- `@webos-tools/cli` pinned to exactly `3.2.6` with a lockfile; it needs Node.js **20+** (its `engines`), so the install scripts check for Node 20+ (Ruling: the spec says 18+, the tool's own floor wins).
- Placeholder hosts only in code, tests, docs: `friend.example.com`, `auth.example.com`, `192.0.2.x`.
- The Developer Mode passphrase is never printed, logged, or written to disk by any script.
- No third-party logos or look-alikes; no "Netflix" or "Seerr" in user-facing text; artwork is FriendFlix's own (`web/static/logo-icon.svg`).
- LG-specific web code runs only when `isLgApp()` is true; the LG browser alone never counts.
- Every new source file starts with the SPDX header used across the repo (`SPDX-FileCopyrightText: 2026 Manuel Weißböck`, `SPDX-License-Identifier: AGPL-3.0-or-later`).
- User-facing web strings go through i18n with both `en` and `de` entries; the local setup pages (`webos/`) are English only, like the Tizen ones.
- Tizen behaviour must not change (its tests and packaging stay green).

## Review Focus

1. LG remotes report `e.key === 'Unidentified'` for media/colour keys — expected: actions still fire from `keyCode` alone (Task 4 test `keyCode only, key Unidentified`).
2. Stored server is down when the app starts — expected: error card with Retry and Change server, never a blank page or a navigation to a dead URL (Task 10 test `unreachable stored server shows the error card`).
3. `canPlayType` throws or `MediaSource` is missing (older webOS) — expected: that check counts as "not confirmed", no exception, block built from the rest (Task 5 test `MediaSource missing and canPlayType throwing`).
4. Back pressed on home while a dropdown or the detail popup is open — expected: the dropdown/popup closes, the app does not exit (Task 3 test `Back on home with a dropdown open closes it, no exit`).
5. Install script run twice, or with a TV already registered under `friendflix-tv` — expected: the device entry is replaced and the app reinstalled, no prompt and no error (Task 12 test `existing device entry is replaced`).
