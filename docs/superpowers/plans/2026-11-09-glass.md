# Glass Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One frosted-glass material across desktop, phone and the admin panel. It includes a fixed-size hover card that always fits, a search sheet under the top bar, and the nine approved motion effects. Calm mode, reduced motion, a tripped frame guard and TV fall back to solid panels.

**Architecture:** A shared glass layer comes first:
- CSS tokens and `.frost*` utility classes in `web/src/app.css`. They key off the existing `html.m-glass` / `html.m-still` / `html.tv` / `html.kids` classes from `routes/+layout.svelte`.
- Three small, fully unit-tested TypeScript modules in `web/src/lib/glass/`: `tone.ts` (contrast and artwork tint), `pointer.ts` (sheen and tilt), `fx.ts` (grow transition, pill parts, count-up, ripple).
- The glass curves, added to `#lib/tv/motion`.

Each later task applies the layer to one area and adds its own e2e tests.

**Tech Stack:** SvelteKit (Svelte 4 syntax, `$:`), TypeScript, vitest (Node, no DOM: browser APIs as doubles like `tint.test.ts`), Playwright (`desktop` and `mobile` projects).

**Spec:** `docs/superpowers/specs/2026-11-09-glass-design.md`

## Global Constraints

- Animate only `transform` and `opacity`. The only exceptions: `stroke-dashoffset` of the toast ring (28 px) and of the save checkmark (20 px), and the selected tab or segment label colour (250 ms). The sliding pill's width change is done with transforms on three parts (cap, scaled middle, cap).
- Use the shared motion system `#lib/tv/motion`: `motionLevel()`, `motionAllowed()` (`#lib/preview`), `frameGuard` with `DESK_GUARD` (desktop and phone) and `TV_GUARD` (TV), plus the new `GLASS_SPRING = 'cubic-bezier(.34,1.56,.64,1)'`, `GLASS_OUT = 'cubic-bezier(.22,1,.36,1)'` and `GLASS_IN = 'cubic-bezier(.4,0,1,1)'`. Any rAF loop calls `watchFrames()` while it runs.
- Calm mode or reduced motion (`html.m-still`): solid panels (`--fr-solid #1c1a21`, no blur, no grain), no effects, instant changes. Blur only with `html.m-glass` (`motionLevel() === 'full'`). A tripped guard drops `m-glass`, so surfaces turn solid. `html.tv` and `html.kids` always get the solid look with the same shapes. No pointer effects on TV.
- Opening and closing animations always run (full: §8 curves; reduced set: 160 ms opacity). Never unmount mid-animation. Only `m-still` switches instantly.
- Contrast: white text on any text-bearing glass is at least 4.5:1. The scrim defaults to `.70`, which passes over pure white. It is lowered only through `scrimFor` on surfaces with a known artwork tone.
- Own look: coral `#ff4f6d`, FriendFlix logo, Inter. Never another streaming service's name or look-alike.
- Touch targets at least 44×44 px. Every new or changed string goes in all seven locales (en, de, pl, es, fr, it, tr); `de` is the type source.
- Owner rules: implementers write the tests and run only the root `npm run typecheck` (running their own specs locally to debug is fine). CI runs vitest and Playwright. Web coverage stays at statements 94 % / branches 89 %, and every `web/src/**/*.ts` counts, so every new `.ts` file gets full unit tests.

**Interfaces (Produces):**

`tone.ts`:
- `type RGB = [number, number, number]`
- Constants: `SCRIM_RGB: RGB = [18,16,24]`, `MILK_RGB: RGB = [236,232,244]`, `MILK_TOP = .19`, `TINT_PEAK = .5`, `SCRIM_MIN = .30`, `SCRIM_MAX = .80`, `SCRIM_SAFE = .70`, `TINT_LUM_MAX = .18`, `AA = 4.5`.
- `luminance(c: RGB): number`: WCAG relative luminance.
- `contrast(a: RGB, b: RGB): number`: `(L1+.05)/(L2+.05)`, with the larger luminance on top.
- `tintColor(c: RGB): RGB`: same hue. It scales the channels down in steps of 1 % until `luminance ≤ TINT_LUM_MAX`, rounded; colours already dark enough are returned unchanged.
- `frostComposite(back: RGB, scrim: number, tint: RGB | null = null): RGB`: sRGB "over" in order: back → `SCRIM_RGB`@scrim → tint@`TINT_PEAK` (when given) → `MILK_RGB`@`MILK_TOP`, rounded.
- `scrimFor(bright: RGB, tint: RGB | null = null, target = AA): number`: the smallest of `SCRIM_MIN…SCRIM_MAX` in .02 steps (2 decimals) with `contrast([255,255,255], frostComposite(bright, s, tint)) >= target`; `SCRIM_MAX` if none.
- `type Tone = { tint: RGB; bright: RGB; scrim: number }`
- `toneOf(px: Uint8ClampedArray): Tone | null`. Only pixels with alpha > 0 count. `tint = tintColor(saturation-weighted mean)`, using the same weights as `dominantColor` in `#lib/tint`. `bright` = per-channel mean of the brightest 10 % by luminance (at least 1 pixel). `scrim = scrimFor(bright, tint)`. Returns `null` when no pixel counts.
- `toneFor(key: string, src: string): Promise<Tone | null>`: loads `src` into a 24×24 canvas (`willReadFrequently`) and returns `toneOf`. Load or taint errors give `null`. The cache is a `Map` keyed by `key`, holding at most 32 entries (oldest out), and it caches `null` too.
- `cachedTone(key: string): Tone | null | undefined`: `undefined` means it was never sampled.
- `toneVars(t: Tone | null): string`: `''` for null, else `--fr-tint:${r}, ${g}, ${b};--fr-scrim:${scrim}` (for `style=`).

`pointer.ts`:
- `fxPointer(o: { level: 'full' | 'reduced'; tv: boolean; kids: boolean; fine: boolean }): boolean`: `o.level === 'full' && !o.tv && !o.kids && o.fine`.
- `fxLive(): boolean`: the same, reading `motionLevel()`, `html.tv`, `html.kids` and `matchMedia('(pointer: fine)')`. False without `document`.
- `sheenAt(r: { left: number; top: number }, x: number, y: number): string`: `` `translate3d(${x - r.left}px, ${y - r.top}px, 0)` `` (numbers rounded to .1).
- `sheen(node: HTMLElement): { destroy(): void }` (Svelte action). It appends `<span class="frost-sheen" aria-hidden="true">`. On `pointerenter` with `fxLive()` it adds `.on`. On `pointermove` it sets the span's `style.transform` via `sheenAt`, throttled to one rAF. On `pointerleave` it removes `.on`. `destroy` removes the listeners and the span.
- `TILT_MAX = 9`, `TILT_EASE = .16`, `TILT_REST = .01`.
- `type TiltState = { x: number; y: number; lift: number }`
- `tiltTarget(r: { left: number; top: number; width: number; height: number }, px: number, py: number, max = TILT_MAX): { x: number; y: number; gx: number; gy: number }`. With `nx = (px − left)/width` and `ny = (py − top)/height`, both clamped to 0..1: `x = (nx − .5)·2·max` (rotateY), `y = −(ny − .5)·2·max` (rotateX), `gx = nx·width`, `gy = ny·height`.
- `tiltStep(cur: TiltState, to: TiltState, k = TILT_EASE): { next: TiltState; done: boolean }`: `next = cur + (to − cur)·k` per field. `done` when the summed absolute differences are `< TILT_REST`; then `next = to`.
- `tiltStyles(s: TiltState, max = TILT_MAX): { card: string; band: string; shadowX: number; shadowScale: number }`. `card = translate3d(0, ${−6·lift}px, 0) rotateX(${y}deg) rotateY(${x}deg) scale(${1 + .06·lift})`, `band = translateX(${x / max · 22}%)`, `shadowX = −x·1.2`, `shadowScale = .9 − .12·lift` (all rounded to 3 decimals).
- `tilt(node: HTMLElement, o: { card: string; glare: string; band: string; shadow: string; row?: string }): { destroy(): void }` (Svelte action on the card wrapper; `o` gives child selectors). On `pointerenter` (with `fxLive()`) it adds `.tilt-on` to the node and `.tilt-row` to `node.closest(o.row)`, sets `to.lift = 1` and starts a rAF loop. Each frame it runs `tiltStep`, writes the transforms (glare: `translate(gx px, gy px)`) and calls `watchFrames()`. On `pointerleave` it sets `to = {0,0,0}` and removes both classes; the loop stops on `done`. Without `fxLive()` nothing moves and the classes stay off.

`fx.ts`:
- `cubicBezier(x1: number, y1: number, x2: number, y2: number): (t: number) => number`: Newton plus bisection on x. `f(0) = 0`, `f(1) = 1`.
- `springEase = cubicBezier(.34, 1.56, .64, 1)`, `inEase = cubicBezier(.4, 0, 1, 1)`, `outEase = cubicBezier(.22, 1, .36, 1)`.
- `type FxMode = 'full' | 'reduced' | 'still'`; `fxMode(): FxMode`. `'still'` when `!motionAllowed()`, `'reduced'` when `motionLevel() === 'reduced'`, else `'full'`.
- `GROW_IN_MS = 380`, `GROW_OUT_MS = 200`, `REDUCED_MS = 160`.
- `growOrigin(trigger: DOMRectLike, pop: DOMRectLike): string`: the trigger centre relative to `pop.left/top`, clamped to `[0, width] × [0, height]`, as `` `${x}px ${y}px` `` (rounded). `DOMRectLike = { left: number; top: number; width: number; height: number }`.
- `grow(node: Element, p: { origin?: string; dir?: 'in' | 'out'; mode?: FxMode } = {}): { duration: number; delay: 0; easing: (t: number) => number; css: (t: number, u: number) => string }` (Svelte transition; `mode` defaults to `fxMode()`):
  - full in: 380 ms, `springEase`, css `transform-origin:${origin};transform:scale(${.4 + .6t});opacity:${min(1, t)}`
  - full out: 200 ms, `inEase`, the same css (Svelte runs `t` 1 → 0)
  - reduced: 160 ms, linear, opacity only
  - still: 0
- `PILL_MID = 100`; `pillParts(t: { x: number; w: number }, h: number): { l: string; mid: string; r: string }`. Caps of diameter `h`. `l = translateX(${x}px)`, `mid = translateX(${x + h/2}px) scaleX(${max(0, w − h)/PILL_MID})`, `r = translateX(${x + w − h}px)`. These are used with a CSS transition `transform 450ms var(--fr-spring)`.
- `COUNT_MS = 1100`; `countAt(to: number, ms: number, dur = COUNT_MS): number`: `round(to · (1 − (1 − min(1, ms/dur))³))`. `dur ≤ 0` gives `to`.
- `rippleBox(r: DOMRectLike, x: number, y: number): { size: number; left: number; top: number }`: `size = 2·max(w, h)`, `left = x − r.left − size/2`, `top = y − r.top − size/2`.

CSS in `app.css`: the spec §1.1 tokens (`--fr-*`, plus `--fr-spring`, `--fr-out`, `--fr-in`) and the §1.2 classes:
- `.frost`, `.frost-flat`, the shape modifiers, `.frost-btn`, `.frost-btn.round`, `.frost-sel`, `.frost-dim`, `.frost-amb`.
- `.frost-sheen` (240 px circle, spec §8.1 gradient, soft-light, `opacity` 300 ms, `.on` → 1).
- `.frost-tint` (two stacked `<i>` layers, opacity 600 ms `--fr-out`, `.on` → .5).
- The fallback selectors `html:not(.m-glass) .frost`, `html.tv .frost`, `html.kids .frost` (and the same three for `.frost-flat`, `.frost-btn`): solid fill, `backdrop-filter: none`, `::before` hidden.
- `html.m-still .frost-sheen, html.m-still .frost-tint, html.tv .frost-sheen { display: none }`.
- The blur rule `html.m-glass:not(.tv):not(.kids) .frost { backdrop-filter: var(--fr-blur); -webkit-backdrop-filter: var(--fr-blur) }`.
